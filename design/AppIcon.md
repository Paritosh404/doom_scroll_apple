# InstaCalm icon

Created with the built-in image-generation tool and exported as an opaque RGB
1024 × 1024 PNG for the iOS AppIcon asset. iOS applies its own corner mask.

Prompt: A clean white rounded-square camera outline and circular lens on a rich
royal-blue to azure gradient, with one small mint-green leaf integrated at the
upper-right corner. Bold, centered, readable at small sizes; no text, border,
device mockup, or pre-rounded outer corners.

The app's display name is InstaCalm. The existing bundle identifier and build
target remain unchanged so sideloaded updates keep the same app identity.
